## Módulo de lectura dinámica

El archivo index.html incorpora la versión v29 del módulo de siete cartas de Ritual Mente. Se puede abrir directamente en un navegador y no necesita dependencias ni recursos externos.

Incluye flotación de 6 segundos, halo de 4 segundos, inclinación con el cursor, selección sincronizada, controles de teclado y adaptación a la preferencia de movimiento reducido. Conserva los siete recorridos, los textos y el precio ARS 14.999,00 del archivo suministrado.

Verificado en escritorio a 1280 x 720 y en móvil a 390 x 844, sin desbordamiento horizontal. Este repositorio contiene el módulo; subirlo a GitHub no actualiza por sí solo la publicación de Sites.
